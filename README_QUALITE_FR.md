# Règles obligatoires de qualité du français

Ce projet est une plateforme destinée à un public francophone, principalement au Bénin et en Afrique francophone.

La qualité du français dans l’interface est obligatoire.  
Aucun texte visible par l’utilisateur ne doit contenir de faute d’orthographe, de grammaire, de conjugaison ou de ponctuation.

## Objectif

Garantir une interface professionnelle, crédible, claire et rassurante pour les utilisateurs.

Une plateforme éducative doit inspirer confiance.  
Des fautes dans les textes visibles peuvent réduire la crédibilité du produit et faire douter l’utilisateur de la qualité des formations proposées.

## Règle principale

Avant toute livraison de code, tous les textes visibles par l’utilisateur doivent être relus, corrigés et validés.

Cette règle s’applique à tous les développeurs, assistants IA, outils de génération de code et contributeurs du projet.

## Textes concernés

La vérification concerne notamment :

- les titres de pages ;
- les titres de sections ;
- les sous-titres ;
- les descriptions ;
- les boutons ;
- les liens ;
- les menus ;
- les labels de formulaires ;
- les placeholders ;
- les messages d’erreur ;
- les messages de succès ;
- les notifications ;
- les modales ;
- les cartes de formation ;
- les cartes de catégorie ;
- les FAQ ;
- les textes marketing ;
- les textes du tableau de bord ;
- les textes d’administration ;
- les emails ;
- les messages automatiques ;
- les textes affichés sur mobile ;
- tout contenu visible par l’utilisateur final.

## Obligations

Chaque texte doit respecter les règles suivantes :

1. Être rédigé en français correct.
2. Ne contenir aucune faute d’orthographe.
3. Ne contenir aucune faute de grammaire.
4. Ne contenir aucune faute de conjugaison.
5. Utiliser correctement les accents.
6. Être bien ponctué.
7. Être clair et compréhensible.
8. Être professionnel.
9. Être adapté au contexte béninois et africain francophone.
10. Être cohérent avec le ton de la plateforme.

## Interdictions

Il est interdit de livrer du code contenant :

- des textes brouillons ;
- des mots mal orthographiész ;
- des phrases incomplètes ;
- des textes de test visibles ;
- des mélanges inutiles entre français et anglais ;
- des fautes d’accord ;
- des fautes de conjugaison ;
- des boutons mal formulés ;
- des messages d’erreur peu clairs ;
- des placeholders non professionnels ;
- des textes incohérents avec le contexte de la plateforme.
